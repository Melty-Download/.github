## What it is

Melty is a free Windows app for **mashups and mods**. A mashup joins two games into one world. SkyCraft is Skyrim played as a Minecraft character. Elden Craft is Minecraft plus Elden Ring. You keep your own copies of the games — Melty just starts them together.

<img src="https://i.imgur.com/XZZYJkU.jpeg" alt="Press Play" width="920">

---

## How it works

| | |
|---|---|
| **1. Download** | Get Melty for Windows from [melty.world](https://melty.world) |
| **2. Discover** | Open SkyCraft, Elden Craft, Super Mario Ring, and more |
| **3. Press Play** | Melty installs what it needs and launches the host game |
| **4. Invite** | Multiplayer mashups give you a link for friends |

Uninstall puts every file back the way it was.
